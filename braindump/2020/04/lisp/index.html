Major points to remember

  • LET doesn’t let you refer to previous variables, so you need to use LET* for that.

  • (progn do_this do_that) –> multiple things to do

  • setting variables: (setq var-name value)

  • Live Demo (write-line “single quote used, it inhibits evaluation”) (write ‘(* 2 3)) (write-line " “) (write-line “single quote not used, so expression evaluated”) (write (* 2 3))

  • require ’elm –> way of loading a library

  • (1 2 3 4) acts as if 1 is a function here so for a list we say ‘(1 2 3 4) so it acts as a literal rather than function and it’s arguments.
